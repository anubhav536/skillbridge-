🎯 Project Overview / Parichay

SkillBridge AI ek production-ready career platform hai jo job seekers, recruiters, aur admins ke liye alag-alag dashboards provide karta hai. Is platform mein AI-powered job matching, career gap analysis, resume builder, aur live analytics shamil hai.

SkillBridge AI is a full-stack career intelligence platform built entirely with Vanilla JavaScript (ES Modules), Firebase v12.11.0, and a Node.js static file server. No frameworks like React or Angular — pure browser-native JavaScript with a beautiful purple-themed dark UI.

🤖 AI-Powered Job Matching (40-factor weighted)
🧠 Career Gap Analyzer with Score Rings
📄 Resume Builder with PDF Export
📊 Live Admin Analytics Dashboard
🏢 Recruiter AI Candidate Ranking
📱 Fully Responsive Dark UI
🔐 Firebase Auth (role-based)
⚡ Real-time Firestore Listeners
🍞 Smart Toast Notification System
💾 Draft Autosave (localStorage)
🟢 Presence / Active Users Tracker
📬 Application Status Management

🧠 AI Engine / AI Kaise Kaam Karta Hai

SkillBridge AI mein koi external AI API nahi hai — sab kuch pure JavaScript mein custom algorithm se hota hai. Isliye koi cost nahi, koi latency nahi, aur offline bhi kaam karta hai.

📊 Weighted Match Scoring (calcWeightedScore)

⚡ Skills Match — 40 points max (job skills vs user skills)
💼 Experience — 20 points (years × 4, adjusted for senior/junior)
🎓 Education — 20 points (PhD/MBA/BTech/Diploma tier)
📝 Resume Keywords — 15 points (job skills in resume text)
🏆 Projects / Certifications — 10 points (bonus)
📬 Recent Activity — 5 points (applications sent)

🔬 Career Gap Analysis (analyzeCareerGap)

Pura job market analyze karta hai — skills frequency map banata hai, user ke skills ko Strong/Weak/Missing mein classify karta hai, Learning Roadmap generate karta hai category-wise (Programming, Web, Cloud, Data AI etc).

📈 Career Readiness Score (0-100)
🎯 Skill Market Match % (top 20 market skills)
🎤 Interview Readiness Score
💪 Strong Skills (user skills in top 15 market)
⚠️ Weak Skills (user skills not in demand)
🚨 Missing High-Demand Skills (top job skills absent)
🗺️ Learning Roadmap by category + priority
💡 5 Personalized AI Suggestions

🏅 Employability Score (calcEmployabilityScore)

Job seeker dashboard pe dikhta hai — skills count (35pts), experience (15pts), total applications (25pts), success rate (25pts). Max 100.

🏗 Architecture / Banawat

Project ka pura structure kaisa hai — data flow kahan se kahan jata hai:

🌐 Browser → Node.js Server (port 5000) → HTML/CSS/JS files serve
📄 HTML → <script type=module> → firebase.js import
🔥 firebase.js → Firebase CDN (v12.11.0) → Auth + Firestore
🤖 ai-match.js → Pure JS algorithms (no API calls)
💡 app-enhancements.js → Toast + UX (loaded at page bottom)
🧠 career-gap.js → analyzeCareerGap() from ai-match.js
💾 localStorage → User session, draft saves, applied jobs cache
🔄 Firestore Realtime → Admin dashboard live counters

🔐 Role-Based Access

Har page apna role check karta hai protectPage() function se. Galat role hone pe redirect hota hai.

👤 jobseeker → js-dashboard, js-jobs, js-profile, career-gap pages
🏢 recruiter → rec-dashboard, rec-applicants, rec-post-job pages
👑 admin → admin-dashboard, admin-users, admin-jobs etc.
🔒 protectPage("role") → getSession() check → redirect if invalid
